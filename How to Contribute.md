## Difficulty Guide

- 🟢 **Beginner** — No prior experience beyond basic syntax. Uses a single library with no external APIs.
- 🟡 **Intermediate** — Combines multiple concepts or deliberately uses an external API/framework.
- 🔴 **Advanced** — Non-trivial setup, multiple moving parts, or deeper CS topics.

## Checklist

- [ ] Link works and is publicly accessible
- [ ] Description is one sentence or less
- [ ] Tech Stack is comma-separated (e.g. `JavaScript, HTML, CSS`)
- [ ] Difficulty matches the guide above
- [ ] One project/resource per row
